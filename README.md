## Experiência Técnica

- Desenvolvimento **Back-end com C# e .NET (4.6 ao .NET 10)** utilizando **ASP.NET Core** e arquitetura em camadas;
- Aplicação de **SOLID, Clean Code e Design Patterns** para garantir código limpo e sustentável;
- Modelagem de domínio e construção de **APIs REST seguras e performáticas**;
- Implementação de **autenticação e autorização com JWT e Basic Auth**;
- Processamento assíncrono e **jobs com Hangfire**;
- Experiência com **Entity Framework e EF Core**, modelagem e otimização de queries;
- Bancos de dados **SQL Server e PostgreSQL**, garantindo consistência e integridade dos dados;
- Desenvolvimento **Front-end com React + TypeScript e TailwindCSS**, criando interfaces modernas e responsivas;
- Experiência com **Blazor**, utilizando bibliotecas como **Radzen e MudBlazor**;
- Integração com **Gateways de pagamento e BaaS**, incluindo **webhooks e validações complexas**;
- Experiência com **observabilidade, logging e monitoramento de integrações críticas**;
- Trabalho em **squads ágeis (Scrum)** utilizando boas práticas de versionamento e entrega contínua.
